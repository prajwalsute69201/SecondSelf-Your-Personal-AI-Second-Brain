# SecondSelf — Static Knowledge Graph Explorer (Task 3.2)

A fast, accessible, dependency-light static frontend that visualizes and explores the generated SecondSelf knowledge graph and PARA-classified items (`Projects`, `Areas`, `Resources`, `Archives`).

Designed for zero-backend static hosting (GitHub Pages, Netlify, Vercel, or local `python -m http.server`) with progressive enhancement, semantic HTML5 landmarks, native ES modules, and WCAG 2.1 AA accessibility compliance.

---

## 1. Quickstart & Local Serving

Because modern browsers enforce CORS restrictions on ES modules (`<script type="module">`) and local JSON fetches (`fetch('data/graph.json')`), serve the `public/` directory with any static HTTP file server:

### Python 3 (Built-in)
```bash
# From workspace root
python -m http.server 8000 --directory public

# Then open in any modern browser:
# http://localhost:8000
```

### Node.js (npx / serve / http-server)
```bash
npx serve public
# or
npx http-server public -p 8000
```

### VS Code Live Server
Right-click `public/index.html` and choose **"Open with Live Server"**.

## 2. Architecture & File Structure

The frontend requires no bundlers (no Webpack, Vite, or Rollup), no compilers, and zero backend:

```
public/
├── index.html            # Semantic HTML5 shell with ARIA landmarks & modal dialogs
├── css/
│   └── main.css          # Design tokens (Slate palette, PARA accents), responsive layout, glassmorphism
├── js/
│   ├── app.js            # Main application orchestrator & lifecycle manager
│   ├── dataLoader.js     # Asynchronous fetcher with candidate URL fallback & defensive validator
│   ├── graph.js          # Force-directed graph renderer (Vis.js Network with Canvas fallback)
│   ├── filters.js        # Reactive filter engine (Search, PARA pills, Confidence, List view)
│   └── detailPanel.js    # Accessible slide-out drawer (metadata, rationale, backlinks)
├── data/
│   └── graph.json        # Precomputed knowledge graph artifact (generated in Task 3.1)
├── graph.json            # Mirrored graph artifact (fallback path)
├── index.json            # 384-dimensional vector embeddings index
├── graph.cypher          # Neo4j/Memgraph Cypher import script
├── graph.graphml         # XML GraphML import document
└── README.md             # This documentation guide
```

## 3. Data Contract (Expected Task 3.1 Schema)

The frontend consumes `graph.json` generated by `secondself-build-graph` (Task 3.1). `js/dataLoader.js` validates and normalizes all incoming fields defensively:

### Expected JSON Structure
```json
{
  "schema_version": "1.0.0",
  "projection_version": "1.0.0",
  "generated_at": "2026-11-23T09:17:30.255242+00:00",
  "corpus_hash": "fb4c2a4a...",
  "statistics": {
    "total_nodes": 32,
    "total_edges": 72,
    "node_counts_by_type": {
      "Item": 24,
      "PARA_Category": 4,
      "Tag": 1,
      "Source": 3
    },
    "edge_counts_by_type": {
      "BELONGS_TO": 24,
      "TAGGED_WITH": 24,
      "EXTRACTED_FROM": 24
    },
    "avg_degree": 4.5,
    "graph_density": 0.1452
  },
  "nodes": [
    {
      "id": "item:0bdc54f2-29a8-43d7-89b6-2d5f9507f1d3",
      "label": "Idea for SecondSelf: force-directed associative layout",
      "type": "Item",
      "group": "Resources",
      "value": 14.09,
      "degree": 3,
      "summary": "Idea for SecondSelf: force-directed associative layout",
      "tags": ["capture"],
      "properties": {
        "record_id": "0bdc54f2-29a8-43d7-89b6-2d5f9507f1d3",
        "title": "Idea for SecondSelf: force-directed associative layout",
        "category": "Resources",
        "confidence": 0.25,
        "rationale": "Reference note without active deadline.",
        "needs_review": true,
        "source_type": "text",
        "created_at": "2026-11-23T08:14:40.287118+00:00",
        "content_hash": "4295ee96...",
        "char_count": 54,
        "word_count": 21,
        "file_path": "wiki/Resources/0bdc54f2-29a8-43d7-89b6-2d5f9507f1d3.md"
      }
    }
  ],
  "edges": [
    {
      "source": "item:0bdc54f2-29a8-43d7-89b6-2d5f9507f1d3",
      "target": "para:resources",
      "from": "item:0bdc54f2-29a8-43d7-89b6-2d5f9507f1d3",
      "to": "para:resources",
      "type": "BELONGS_TO",
      "value": 1.0,
      "title": "BELONGS_TO",
      "properties": {
        "category": "Resources",
        "confidence": 0.25,
        "method": "rules"
      }
    }
  ]
}
```

### Defensive Handling of Schema Variations
- **Dual Edge Aliases:** Both `from`/`to` (Vis.js standard) and `source`/`target` (D3.js / NetworkX standard) are supported.
- **Missing Properties:** If `confidence` is omitted, the confidence meter gracefully disappears; if `rationale` is missing, an explainable fallback statement is derived from node type.
- **Dangling Edges:** Any edge whose endpoint node ID is missing from `nodes` is dropped with a console warning rather than crashing graph rendering.
- **Duplicate Prevention:** Nodes and edges with identical IDs or keys are deduplicated during ingest.

## 4. UI State & Visual Walkthrough

### 1. Default State (Initial Load)
- **Top Header:** Deep slate bar (`#0f172a`) displaying the "SecondSelf" badge, dynamic stats chips (`Total: 32`, `Projects: 0`, `Areas: 0`, `Resources: 24`, `Archives: 0`, `Links: 72`), and view switch tabs (`Graph` active, `List`).
- **Toolbar:** Centered search box with keyboard indicator `[/]`, four colored PARA filter pills (`Projects` [Amber], `Areas` [Blue], `Resources` [Green], `Archives` [Slate]), minimum confidence range slider (`0.00`), and live counter (`Showing all 32 nodes`).
- **Main Stage:** Fullscreen 2D force-directed canvas. Nodes gently settle into associative clusters:
  - The green `para:resources` hub node anchors the center.
  - 24 note item nodes orbit in surrounding clusters, connected by subtle relationship lines.
  - Purple tag nodes and pink source nodes branch outward.
  - Bottom-right floating controls provide Zoom (`+`/`-`), Fit (`⛶`), and Freeze Physics (`⚡`).
  - Bottom-left floating legend categorizes node colors and shapes.

### 2. Interactive Selection & Neighborhood Highlighting
- Clicking any note node (e.g. `Idea for SecondSelf: force-directed associative layout`):
  - Dims all non-connected nodes and unrelated edges to low opacity (20%), isolating the immediate 1st-degree neighborhood in full vibrancy.
  - Smoothly slides out the right-hand **Detail Drawer** (`440px` wide, with backdrop blur).
  - The drawer displays:
    1. Category Pill: `RESOURCES` (Green badge).
    2. Confidence Meter: `25%` with status indicator (`Needs Review` badge).
    3. Rationale Box: Explainable decision criteria.
    4. Note Summary: Full text preview.
    5. Interactive Tags: Clickable `#capture` pill (filters graph on click).
    6. Connected Relationships: Clickable links to `para:resources` (`BELONGS_TO`), `#capture` (`TAGGED_WITH`), and `text` (`EXTRACTED_FROM`). Clicking any backlink immediately navigates to and focuses that node.
    7. Provenance Grid: Record UUID, source type, timestamp, word count, file path, and SHA-256 hash.

### 3. List / Card Explorer Mode
- Toggling the **List** tab in the header smoothly reveals an accessible responsive grid of cards:
  - Each card highlights the note title, PARA category badge, confidence progress bar, text snippet, tags, and link count.
  - Fully accessible via keyboard (`Tab` to navigate, `Enter` to open details).

## 5. Accessibility (WCAG 2.1 AA)

- **Color Independence:** Colors are never used as the sole indicator. PARA categories pair distinct hues (Amber, Blue, Green, Slate) with text labels, icons, and distinct node shapes (boxes for categories, circles for items, diamonds for tags, triangles for sources).
- **High Contrast:** All text tokens exceed WCAG 2.1 AA minimum contrast ratio (Text primary `#f8fafc` on `#090d16` canvas exceeds `13:1`; secondary text `#cbd5e1` exceeds `7:1`).
- **Keyboard Navigation:**
  - Press `/` anywhere to focus the search bar.
  - Press `Esc` to close the detail drawer or clear active search.
  - Press `f` to fit/re-center the graph.
  - Interactive cards and buttons feature high-contrast focus rings (`outline: 2px solid #38bdf8; outline-offset: 2px`).
- **Screen Reader Support:**
  - Semantic HTML5 landmarks (`<header>`, `<main>`, `<aside>`, `<nav>`).
  - `aria-live="polite"` live region on the results counter announces filter changes (e.g., *"Showing 18 of 32 nodes"*).
  - Modal drawer uses `role="dialog"`, `aria-modal="true"`, `aria-labelledby="drawer-title"`, and focus trapping.

## 7. Zero-Backend Production Deployment

Because all files in `public/` are pure static assets (HTML, CSS, JS, JSON):

### GitHub Pages
1. Push `public/` to your GitHub repository (or configure GitHub Pages to deploy from `docs/` or the `public` folder on `main`).
2. Set build source to **"Deploy from a branch"** -> `/root` (if deploying public branch) or using the official GitHub Pages Action.

### Netlify
```bash
npx netlify deploy --dir=public --prod
```

### Vercel
```bash
npx vercel public --prod
```
