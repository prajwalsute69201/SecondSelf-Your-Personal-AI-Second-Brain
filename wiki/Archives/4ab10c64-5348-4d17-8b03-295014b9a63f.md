# Archive: Streamlit Second Brain Prototype (Deprecated)
Decision: Abandoned in favor of Jamstack + Vercel Serverless.
Reasons for deprecation:
- Streamlit requires persistent long-running Python containers with stateful WebSockets.
- Canvas reruns entire script on every user click, making graph traversal stutter.
- Hosting costs on EC2/Render were unnecessary when static HTML/Canvas + Vercel is free.
