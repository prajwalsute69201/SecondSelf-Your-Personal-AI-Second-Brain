# Area: Personal Software Engineering Standards
Principles to uphold across all projects:
1. Strict Twelve-Factor App compliance: Config in environment, never hardcode secrets.
2. Dual-Plane Separation: Heavy ML dependencies belong strictly in requirements-dev.txt.
3. GitOps truth: Knowledge files in Git are the primary database; cloud deployments are read-only projections.
4. Comprehensive test coverage for core business logic.
