# Resource: Metric Selection in High-Dimensional Vector Search
Key comparisons:
- Cosine Similarity: Measures angle between vectors; invariant to vector magnitude. Best for normalized text embeddings where document length varies.
- Dot Product: Measures angle and magnitude. Equal to cosine similarity when vectors are L2-normalized.
- Euclidean (L2) Distance: Measures geometric distance; sensitive to token length without normalization.
For all-MiniLM-L6-v2 (384-d), always use normalized dot product for maximum speed.
