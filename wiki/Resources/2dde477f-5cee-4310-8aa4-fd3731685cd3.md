# Resource: Decoupled Serverless RAG Design
How to serve vector search in ephemeral Lambdas under 50 MB:
1. Precompute all document embeddings locally during the build phase using sentence-transformers.
2. Export the embedding matrix and metadata as a compact JSON lookup (public/index.json).
3. In the serverless function (api/ask.py), vectorize the user query and run a vectorized dot-product using pure NumPy.
4. Latency: < 15ms retrieval time, zero torch/CUDA dependencies.
